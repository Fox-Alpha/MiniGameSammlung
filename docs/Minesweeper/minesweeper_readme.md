# MineSweep Pro

Ein moderner Minesweeper-Klon mit erweiterten Features und verbesserter Benutzerfreundlichkeit.

## 🎮 Über das Spiel

MineSweep Pro ist eine zeitgemäße Interpretation des klassischen Minesweeper-Spiels. Decke alle minenfreien Felder auf, ohne eine Mine zu treffen! Das Spiel bietet verschiedene Schwierigkeitsgrade, detaillierte Statistiken und ein intuitives Interface.

### ✨ Features

- **Klassische Spielmodi**: Anfänger (9×9), Fortgeschritten (16×16), Experte (30×16)
- **Benutzerdefinierte Felder**: Wähle deine eigene Größe und Minenzahl
- **Intelligente Mechanik**: Erste Aufdeckung ist immer sicher
- **Statistiken & Achievements**: Verfolge deine Fortschritte und Bestzeiten
- **Moderne UI**: Minimalistisches Design mit Retro-Elementen
- **Audio-Feedback**: Immersive Soundeffekte (optional)

## 🎯 Spielanleitung

- **Linksklick**: Feld aufdecken
- **Rechtsklick**: Flagge setzen/entfernen  
- **Mittelklick**: Schnelles Aufdecken (wenn genug Flaggen gesetzt)
- **Zahlen**: Zeigen die Anzahl benachbarter Minen an

### Ziel
Decke alle Felder auf, die keine Minen enthalten, ohne dabei eine Mine zu treffen!

## 🚀 Installation

```bash
# Repository klonen
git clone https://github.com/username/minesweep-pro.git

# In Projektordner wechseln
cd minesweep-pro

# Abhängigkeiten installieren
npm install

# Spiel starten
npm start
```

## 🎮 Steuerung

| Eingabe | Aktion |
|---------|--------|
| Linksklick | Feld aufdecken |
| Rechtsklick | Flagge setzen/entfernen |
| Mittelklick | Schnelles Aufdecken |
| F2 | Neues Spiel |
| Esc | Menü öffnen |

## 📊 Schwierigkeitsgrade

| Modus | Größe | Minen | Empfohlene Zeit |
|-------|-------|-------|-----------------|
| Anfänger | 9×9 | 10 | 1-3 Minuten |
| Fortgeschritten | 16×16 | 40 | 3-8 Minuten |
| Experte | 30×16 | 99 | 10-30 Minuten |

## 🏆 Achievements

- **Speedrun**: Löse Felder unter Zeitdruck
- **Präzision**: Gewinne ohne unnötige Flaggen
- **Ausdauer**: Erreiche lange Gewinnsträhnen
- **Perfektion**: Meistere alle Schwierigkeitsgrade
